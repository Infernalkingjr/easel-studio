Better together

Send work from one app to the next.

The apps hand files to each other. Round-trip edits always work on copies, so your originals never change.

→
Easel to Reel, Flip, Quill and FolioSend to adds your image as a clip, an animation layer, artwork or a PDF page.
⇄
Edit in EaselOpen a photo clip in Easel. When you press ⌘S there, Reel updates. Frame → Easel grabs a video frame.
⇄
Edit in ToneClean up a music clip in Tone, and the soundtrack in Reel updates. Send Mix to Reel adds new music.
→
Flip to ReelAnimations drop into your video, and transparent backgrounds stay transparent.
→
Quill to FolioArtwork arrives as a vector PDF, so it stays sharp. Quill also sends PNGs to Easel, Reel and Flip.
→
Folio to Easel or ReelSend any PDF page as a picture to edit it or put it in a video.

Shared files live in ~/Library/Application Support/Easel Studio/.

Install

Pick the installer you like.

All three install the same apps into your Applications folder.

Disk image (.dmg)

Open it, then drag the apps you want onto Applications.

Download .dmg

Installer package (.pkg)

A step-by-step installer that lets you tick which apps to install.

Download .pkg

Terminal

One command, with no security prompts. Add app names to install only those, or --uninstall to remove them.

View install.sh

Opening the apps the first time

  1. Easel Studio isn't notarized by Apple yet, so macOS may say an app “can't be opened” or “is damaged”.
  2. Right-click (Control-click) the app in Applications and choose Open, then Open again. Or go to System Settings → Privacy & Security and click Open Anyway.
  3. For the .pkg, do the same: right-click it and choose Open.
  4. You only have to do this once per app. The Terminal installer skips it entirely.

Open source

Build it yourself.

You need Swift 5.9 or later (Xcode or the Command Line Tools) on macOS 14 or later.

# get the code
git clone https://github.com/Infernalkingjr/easel-studio.git
cd easel-studio

# build all six apps into build/ (or name one: easel, reel, tone, flip, quill, folio)
./Scripts/build_app.sh

# package build/ as dist/EaselStudio.dmg, .pkg and .zip
./Scripts/make_installers.sh
